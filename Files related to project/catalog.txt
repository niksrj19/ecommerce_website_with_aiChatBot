"Implement a paginated and filterable product listing API endpoint (GET /api/products).

Request Query Parameters:



page (number, default: 1)

limit (number, default: 20)

size (comma-separated list or array, optional)

color (comma-separated list or array, optional)

category (string or array, e.g., 'sports', 'casual', optional)

brand (string or array, optional)

minPrice & maxPrice (numbers, optional for price range filtering)

Backend Implementation Requirements:



Use Prisma to construct a dynamic where clause to filter products on the database level using where, AND, in, and gte/lte for prices.

Apply offset-based pagination using skip: (page - 1) * limit and take: limit.

Return a JSON response containing:

products: Array of 20 filtered items.

pagination: { totalItems, totalPages, currentPage, limit }."
